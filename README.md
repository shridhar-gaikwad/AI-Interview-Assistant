# 🤖 AI Interview Assist

AI Interview Assist is a smart application designed to help candidates prepare for interviews by simulating AI-driven Q&A sessions.  
It leverages modern AI models to provide realistic interview practice, explanations, and guidance.

---

## 🛠 Tech Stack
- **Java 17**
- **Spring Boot**
- **Spring AI**
- **Maven 3.9.16**
- **Docker 29.6.1**
- **Git 2.45.1**
- **Ollama** (for running local AI models)

---

## ⚙️ System Requirements
You only need **Docker Desktop** installed. All other dependencies (Java, Maven, Ollama) are containerized.
